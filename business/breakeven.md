# breakeven.md

## Cost per Active User (CAU)
- **Compute**: $0.0025/user/mo (serverless functions, container orchestration)
- **Storage**: $0.0005/user/mo (code analysis cache, user profiles)
- **Bandwidth**: $0.001/user/mo (API calls, file transfers)
- **Total CAU**: **$0.004/user/mo**

## Pricing Tiers
1. **Starter** ($9/mo)
   - 100k lines/month code analysis
   - Basic refactoring suggestions
   - Email support

2. **Professional** ($29/mo)
   - 500k lines/month code analysis
   - Advanced refactoring rules
   - Priority support
   - Integration with GitHub/GitLab

3. **Enterprise** ($99/mo)
   - Unlimited code analysis
   - Custom rule sets
   - Dedicated account manager
   - SSO & audit logs

## CAC Range
- **Average CAC**: $120-$180 (marketing + sales + onboarding)
- **CAC Breakdown**: 
  - Marketing: $60-$90
  - Sales: $30-$45
  - Onboarding: $30-$45

## LTV Estimate
- **LTV/Starter**: $108/mo (12mo retention)
- **LTV/Professional**: $348/mo (12mo retention)
- **LTV/Enterprise**: $1,188/mo (12mo retention)
- **Average LTV**: **$420/mo**

## Break-even Users Count
- **Break-even users**: **1,000 users**
- **Break-even MRR**: **$4,200/mo**
- **Break-even period**: **~3 months** (assuming $10K initial investment)

## Path to $10K MRR
- **Tier Mix**: 100 Professional users + 100 Enterprise users
- **MRR Breakdown**: 
  - 100 × $29 = $2,900
  - 100 × $99 = $9,900
  - **Total**: $12,800/mo
- **Time to $10K MRR**: **~2 months** (with aggressive growth strategy)
- **Required Users**: **1,000 users total** (assuming 50% Professional, 50% Enterprise)
