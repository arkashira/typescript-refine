# TypeScript Refine

This project provides a simple demo of a TypeScript project with a clear, executable start script and minimal build configuration.

## Getting Started

1. Install dependencies: `python -m pip install -r requirements.txt`
2. Build the project: `python -m pytest`
3. Run the project: `python src/typescript_refine.py`
4. Run the test: `python -m pytest tests/test_typescript_refine.py`

## Commands

* `npm install`: Install dependencies
* `npm run build`: Build the project
* `npm start`: Run the project
* `npm test`: Run the test
