# 🚀 typescript-refine

**Power developers with a simple TypeScript project.** A clear start script and minimal build configuration make it easy to get started with TypeScript development.

## Why typescript-refine?

* **Easy to start**: A simple executable start script gets you up and running quickly.
* **Minimal build configuration**: Focus on writing code without worrying about complex build settings.
* **Test-driven development**: Use Pytest to write and run unit tests.
* **Python integration**: Leverage the power of Python in your TypeScript project.
* **TypeScript expertise**: Develop your skills with a well-structured TypeScript project.

## Getting Started

1. Clone the repository: `git clone https://github.com/axentx/typescript-refine.git`
2. Install dependencies: `poetry install`
3. Run the start script: `poetry run start`
4. Write and run unit tests: `poetry run pytest`

## Deploy

1. Build the project: `poetry build`
2. Deploy to your desired target (e.g., Vercel, AWS Lambda)
